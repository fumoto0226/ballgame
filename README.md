# Falling Ballz · 无限弹球

纯 HTML / CSS / JavaScript，无构建工具、无第三方依赖。直接用浏览器打开 `index.html` 即可游玩，也可在目录运行 `python3 -m http.server 5173`。

- 按住画面拖动瞄准，松开发射一组 24 颗球。
- 命中数字减一，颜色随剩余数字变化，归零消失。
- 方块固定，底部回收完毕后可继续发射，清空全部方块即完成。
- 顶部暂停、1× / 2× 倍速，底部重新开始。空格暂停，F 全屏。

## 文件

- `index.html`：页面结构和按钮。
- `css/style.css`：手机竖屏适配和黑色背景。
- `js/game.js`：关卡布局、碰撞物理、绘制和交互。

修改 `reset()` 内的数组可调整形状、坐标、尺寸、数字和旋转角度。`TOTAL` 控制每轮球数。最高命中记录保存在本地浏览器。
