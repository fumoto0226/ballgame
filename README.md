# Falling Ballz · 旋转弹球

纯 HTML / CSS / JavaScript，无构建工具、无第三方依赖。浏览器直接打开 `index.html`，或运行 `python3 -m http.server 5173` 后访问本地页面。

## 玩法

- 用鼠标或手指沿圆盘拖动，所有方块围绕圆心旋转，自身角度也同步旋转，数字始终正向。
- 点击「发射」，自动把一整组 24 颗球沿中央垂直方向依次发出，不需要持续按住。
- 每次碰撞扣一点数字，颜色随剩余数字改变，归零消失。圆盘轮廓不阻挡球。
- 小球进入底部灰色区域后继续落出屏幕；最后一颗球离屏后，所有球从屏幕顶部落回球仓。
- 回仓结束后可再次发射；发射期间仍可转动圆盘。清空后点击「再来一局」，右下角 ↻ 可随时重置。

## 文件

- `index.html`：页面结构和发射按钮。
- `css/style.css`：手机竖屏适配、黑色外围与按钮样式。
- `js/game.js`：圆盘旋转、碰撞、绘制和发射/回收状态。

`reset()` 数组依次定义形状、相对圆心的横纵坐标、尺寸、生命数字和初始角度。支持 `square`、`circle`、`triangle`。`TOTAL` 控制每轮球数。
