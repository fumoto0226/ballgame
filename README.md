# Falling Ballz · 旋转弹球

纯 HTML / CSS / JavaScript，无构建工具、无第三方依赖。浏览器直接打开 `index.html`，或运行 `python3 -m http.server 5173` 后访问本地页面。

## 玩法

- 每局初始有 **5 次发射机会**，每发射整组球消耗 1 次，顶部实时显示剩余次数。
- 白色描边特殊方块上方显示生命数字，下方显示「+3击」，需要命中 3 次，击碎后增加 **3 次发射机会**，每块仅奖励一次。
- 清空全部普通、隐藏层和特殊方块才算赢。机会用尽时会等本轮球全部离场和回仓，再判失败；最后一轮获得奖励仍可继续。胜负后按钮可重新开始，机会恢复为 5 次。

- 用鼠标或手指沿圆盘拖动，所有方块围绕圆心旋转，自身角度也同步旋转，数字始终正向。
- 点击「发射」，自动把一整组 24 颗球沿中央垂直方向依次发出，不需要持续按住。
- 每次碰撞扣一点数字，颜色随剩余数字改变，归零消失。圆盘轮廓不阻挡球。
- 灰色弧面可反弹小球，反弹后还能继续击中方块；低速时沿弧面滚动离场。四周为开放边界，小球从任意边缘完全离屏就结束本轮运动，最后一颗离开后整批从顶部回仓。
- 回仓结束后可再次发射；发射期间仍可转动圆盘。清空后点击「再来一局」，右下角 ↻ 可随时重置。

## 文件

- `index.html`：页面结构和发射按钮。
- `css/style.css`：手机竖屏适配、黑色外围与按钮样式。
- `js/palette.js`：根据参考截图取样的数字配色，未采用官方源码或官方色表。
- `js/block-geometry.js`：统一形状面积、轮廓和重叠检测。
- `js/game.js`：圆盘旋转、碰撞、绘制和发射/回收状态。

`reset()` 随机生成三组双层方块，第一层数字为 3 或 5，第二层为 21–29；混合 `square`、`circle`、`triangle`。每个第二层方块与一或两个第一层方块重叠，所有形状和特殊方块均按实际轮廓重叠生成 `coveredBy` 遮挡关系，支持第三层及更多层级。覆盖者全部消除前，方块暗化、不显示数字、不参与碰撞；全部消除后自动提升。旋转不会改变覆盖关系。`INITIAL_ATTEMPTS` 控制初始机会，`BONUS_ATTEMPTS` 控制奖励次数。`TOTAL` 控制每轮球数，`R` 统一待发、发射和回收动画的小球尺寸。

## 配色来源

未查到 Falling Ballz 官方公开的数字色表或源码。官方产品页：https://apps.apple.com/us/app/falling-ballz/id1298197591 。当前以用户最早提供的游戏截图为视觉依据，取块内部主色（RGB），并在 HSV 空间插值，保持色彩鲜艳。

| 数字 | 截图取样色值 |
| --- | --- |
| 2 | #F8D347 |
| 5 | #FEF751 |
| 32 | #76FB6C |
| 37 | #77FA9C |
| 38 | #75FBA6 |
| 72 | #4B08F5 |

截图未展示的数字为近似插值；小于 2、大于 72 的数字暂时使用最近端点色。后续取得完整色表时可修改 `js/palette.js` 的 `anchors` 数组。

所有方块当前使用同一面积（约 1257 平方逻辑像素，size=1），按圆、正方形、等边三角形的面积换算尺寸，让视觉份量一致；特殊方块也使用同一尺寸。绘制、碰撞与遮挡检测共享轮廓。

隐藏层使用完全不透明的深色填充，通过降低配色亮度来暗化，能够完整遮住其下的图形。
