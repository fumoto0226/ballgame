# 005 · 破局 · 回响（取舍版）

18层、455块砖。开局8颗小普通球、3次发射、10°底部弹力板。每层20～35块；通过真实轮廓接触建立遮挡，所有后层砖都有覆盖者，没有同层相交。

## 疏密节奏

六层一个段落，共三段：双环、交错棋阵、双堡选择、偏置四岛、留白星轨、密墙爆破。外环与内环有大球通道，方阵通常采用62像素中心距，四岛采用60像素中心距；少量覆盖衔接砖会缩小局部通道。双堡围墙和密墙是有意设计的紧密区域，其他区域以留白和通道为主。

普通砖血量按段抬高，末段基础HP为750、1000、1400、1900、2500、2500。强化、弹力板与球数补给穿插其间；没有单颗高血量尾砖作为关底。

## 有限资源与选择

全关只有七块+1次发射补给（含末层中央的最后续命砖），理论总预算10次，错过补给会更早耗尽。原版每次+2以及频繁翻倍被削减，单次大规模强化也减少。

第3、9、15设计层设双堡：左侧×2球，右侧爆炸强化（20、48、96点强化储量）。先打穿环墙才能稳定接触内核。墙首次暴露的那一发计为第一回合，下一发是第二回合；第三发开始，未获取的奖励失效，保留原HP成为普通砖。提前发射、未完全回收、奖励尚被覆盖，都不会绕过计时。

两个核心属于同一选择组：获得一个核心奖励后，另一个变普通砖。爆炸强化以首次有效强化视为作出选择，球数奖励以打掉核心为准。被遮挡核心不显示名称、数值或倒计时；露到最上层后显示奖励标签，白边按回合分段减少。组间相互独立，后面的选择不会在开局提前到期。

## 防卡保护

新暴露砖块进入物理场时，检测其是否包住在飞小球。以球当前位置为中心搜索最近可容纳完整球体的空隙，核对所有已暴露砖块、外墙、顶板和弹力板，避免只推出一块砖又进入下一块。找到空位后赋予沿脱离方向的速度；这一过程不产生伤害或奖励。距离精度为2个逻辑像素，候选之间约2像素间隔。

## 验证与维护

生成器：`node scripts/build-level-005.cjs`。覆盖回归测试包含密墙整体脱困、内部最近间隙、正常接触不跳位、两次发射后失效、隐藏阶段不提前计时、二选一失效、关卡真实层级与轮廓检查。

关卡仍通过LevelCatalog读取，已有浏览器同名用户保存优先，不覆盖编辑器保存数据。难度为固定设计，没有动态补发机会或按玩家进度修改血量。

最终版种子92的完整实物理试玩：10发通关，剩余0次，114球；第8发还剩5块、第9发还剩1块，第10发完成。最后一击时仍有49球在场，立即结算成功。此轨迹全程不转盘，说明随机反弹存在过关路径，并不保证其他随机轨迹或操作也会成功。
另一条种子7、按奖励/血量优先瞄准的轨迹因错过补给，第8发耗尽机会，剩74块；同一最终版本存在失败结果。以上是两条验证记录，不是胜率估计。
